
# AI Log - Praktikum Pertemuan 10

## Penggunaan AI

AI digunakan sebagai alat bantu dalam memahami dan menyelesaikan praktikum Laravel Database & CRUD I.

### Bantuan yang Digunakan

1. Membantu memahami konfigurasi database MySQL pada Laravel.
2. Membantu memeriksa struktur migration tabel courses.
3. Membantu membuat dan memeriksa model Course.
4. Membantu mengembangkan CourseController.
5. Membantu membuat form tambah kursus.
6. Membantu memperbaiki validasi input kursus.
7. Membantu memeriksa proses penyimpanan data ke database.
8. Membantu menyusun dokumentasi dan bukti praktikum.

### Hasil Pengerjaan

Database kursusku berhasil dibuat dan dihubungkan dengan Laravel. Tabel courses berhasil dibuat sesuai kebutuhan praktikum. Model, controller, dan form tambah kursus juga telah dibuat.

Sebanyak 8 data kursus berhasil ditambahkan ke database MySQL.
